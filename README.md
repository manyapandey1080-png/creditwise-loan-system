# 💳 Creditwise Loan System

A machine learning-based system designed to predict loan approval status based on applicant data. This project helps automate and improve decision-making in financial institutions by analyzing key factors such as income, credit history, and other relevant attributes.


## 🚀 Features

* 📊 Data preprocessing and cleaning
* 🤖 Machine learning model for loan prediction
* 📈 Model training and evaluation
* 🧠 Intelligent decision support system
* 📁 Structured and modular codebase


## 🛠️ Tech Stack

* **Programming Language:** Python
* **Libraries:** Pandas, NumPy, Scikit-learn
* **Model Storage:** Pickle (`.pkl`)
* **Environment:** VS Code

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

git clone https://github.com/manyapandey1080-png/creditwise-loan-system.git
cd creditwise-loan-system

### 2️⃣ Install dependencies


pip install -r requirements.txt

### 3️⃣ Run the project

python train_model.py



## 📊 How It Works

1. Loads dataset and preprocesses data
2. Trains a machine learning model
3. Saves the trained model (`model.pkl`)
4. Uses the model to predict loan approval
